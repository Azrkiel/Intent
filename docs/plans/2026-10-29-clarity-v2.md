# Clarity v2 implementation plan

Goal: implement [the clarity v2 spec](../specs/2026-10-29-clarity-v2.md) and the
still-applicable parts of [the proposal](2026-10-29-clarity-v2-proposal.md):
North Star rubrics questioned until clear, atomic claims with computed provenance,
scenario approval, divergence-driven decisions and canary-calibrated review.

Architecture: a new `backend/app/clarity/` package. Pure, deterministic modules
(provenance, North Star evaluation, decisions, canaries) are wrapped by one
`ClarityPipeline` that the engine calls instead of the v1 framework map for
sessions with `clarity_version == 2`. The application computes every status,
score and blocker; models return narrow validated drafts. The frontend adds a
Clarity panel and scenario approval.

Stack: Python 3.11, Pydantic 2, FastAPI, pytest; Next.js 16, React 19,
TypeScript, Vitest, Playwright.

## Decisions this plan makes (flag to the user before execution)

1. **Per-session version.** `Session.clarity_version` (1 or 2) is fixed when a
   session is created, like `mode`. Defaults: live → 2, demo → 1. `CLARITY_VERSION`
   overrides, and `POST /api/sessions` accepts `{"clarity_version": 2}`.
   Historical sessions stay on v1. This leaves v1 demo flows, the 16 scripted evals and the
   existing browser tests unchanged.
2. **Propose and confirm (user-approved 2026-10-29).** Every North Star follow-up
   carries Intent's extrapolated draft, filling the gaps a non-expert would not know,
   plus the assumptions it made. The user then picks a draft, edits it or writes
   their own. Any reply to a North Star follow-up answers it, which keeps
   "prompted once" deterministic.
3. **Drafts** are screened for vague words (G1) before they are offered. A picked draft
   becomes the user's turn verbatim, labeled as drafted by Intent. A field built
   entirely from picked drafts skips the separate read-back (G3); the rubric and G4 still run.
4. **Aspects:** every area/aspect needs a claim or a `not-applicable` entry citing
   a confirmed requirement. Gaps are filled by proposals, which the user approves
   under "What I filled in for you". Ambition is not parsed into required aspects.
5. **Deferred decisions** must carry a `due_phase` such as `P2`, and they reach
   the planner as reviewed context. Planner-side enforcement against the plan
   contract is **not** in this plan; it needs a planning change.

## Flows

```text
utterance -> invalidate (clarity=None; readbacks/vetoes kept) -> extract -> six critics
                                                                     | critic questions = seeds
                                                                     v
 North Star:  quotes(Nano) -> lexicon G1 (app) -> rubric judge + reader probes (Nano)
              -> readers A,B (Nano) -> alpha G4 (app) -> read-back G3 (user click)
              |  any field failing -> extrapolated drafts + assumptions (Nano, G1-screened)
              |     -> "My best guess: ... I filled in: ... Does that fit?" -> pick | edit | own words
              |  picked draft -> turn (labeled) -> field from drafts skips G3; rubric + G4 rerun
              v  all six pass
 Claims:      claims map (Super) -> provenance (app): status, tiling, novelty, delegation, aspects
              -> one repair with problems -> scenarios (Super) -> scenario rules (app)
 Decisions:   decision probes (Super) -> 4 candidate builders answer (Nano, temp 0.9)
              -> divergence, split, score, disposition, stop rule, DQ links (app) + vetoes
 Review:      plant canaries (app) -> reviewer (Super) on mutated copy; entailment (Nano);
              round-trip + align (Nano) -> recall, trusted, real findings (app)
              v
 Gate (app): fields pass; no provenance/scenario/decision problems; trusted review;
             scenarios exist -> "Approve scenarios + What I filled in for you" -> compile -> planner

Error states: any ModelError/ValueError -> state.failures -> analysis_complete False -> gate closed.
Budget exhaustion is a ModelError. A stale revision/hash -> "clarity review is stale".
Read-back for an outdated text_hash -> HTTP 409. A veto of a non-delegated decision -> HTTP 409.
```

```python
"""Clarity v2 contracts. Models propose drafts; the application computes status and readiness."""

from typing import Annotated, Literal

from pydantic import BaseModel, ConfigDict, Field, StringConstraints

Text = Annotated[str, StringConstraints(strip_whitespace=True, min_length=1, max_length=1500)]
Short = Annotated[str, StringConstraints(strip_whitespace=True, min_length=1, max_length=300)]
Identifier = Annotated[str, StringConstraints(strip_whitespace=True, min_length=1, max_length=80)]
ClaimText = Annotated[str, StringConstraints(strip_whitespace=True, min_length=1, max_length=400)]

NorthStarField = Literal["who-when", "job", "ambition", "today", "good", "fails-if"]
# Question order: who/job/ambition set proportionality for the rest (spec §2.3).
NORTH_STAR_FIELDS: tuple[str, ...] = ("who-when", "job", "ambition", "today", "good", "fails-if")
FIELD_LABELS = {
    "who-when": "Who & when",
    "job": "Job",
    "ambition": "Ambition",
    "today": "Today",
    "good": "Good looks like",
    "fails-if": "Fails if",
}
RUBRIC: dict[str, tuple[str, ...]] = {
    "who-when": ("W1", "W2", "W3", "W4"),
    "job": ("J1", "J2"),
    "ambition": ("A1", "A2", "A3"),
    "today": ("T1", "T2"),
    "good": ("O1", "O3"),
    "fails-if": ("F1", "F2"),
}
# Prompted once for higher clarity; never blocking by themselves (spec §2.1-2.2).
PROMPT_ONCE_RULES: dict[str, tuple[str, ...]] = {"good": ("O2",)}
RULE_TEXT = {
    "W1": "name a person or group you can identify, not 'users' or 'people'",
    "W2": "describe the moment that makes them reach for it",
    "W3": "say which device or place they use",
    "W4": "say how often it happens",
    "J1": "use one verb and one object, without 'and' or 'or'",
    "J2": "describe the job without naming a feature or technology",
    "A1": "choose throwaway, personal tool, shared with a few people, or product",
    "A2": "say who else will use it",
    "A3": "say how long it should last",
    "T1": "name how this is done today",
    "T2": "name one concrete pain with today's way",
    "O1": "give a direction, a measure, an object and a context",
    "O2": "put a number with a unit on it",
    "O3": "describe the outcome without naming a feature",
    "F1": "describe a failure you could observe: if something happens, then what you see",
    "F2": "make that failure specific to this product",
}

Basis = Literal["stated", "entailed", "delegated", "proposed", "excluded"]
ClaimStatus = Literal["confirmed", "derived", "proposal", "excluded"]
Kano = Literal["must-be", "performance", "delighter"]
Category = Literal["data-model", "identity", "external", "destructive", "behavior", "presentation", "other"]
ScenarioKind = Literal["journey", "failure", "exclusion"]
FindingKind = Literal["invented", "omitted", "negated", "miscited", "scope-creep", "vague", "other"]


class Contract(BaseModel):
    model_config = ConfigDict(extra="forbid")


class Thresholds(Contract):
    alpha_pass: float = Field(default=0.80, ge=0, le=1)
    alpha_floor: float = Field(default=0.667, ge=0, le=1)
    canary_critical_recall: float = Field(default=1.0, ge=0, le=1)
    canary_overall_recall: float = Field(default=0.80, ge=0, le=1)
    decision_stop: float = Field(default=1.5, ge=0, le=9)
    repeat_penalty: float = Field(default=0.5, ge=0, le=9)


# Model outputs: North Star.
class FieldQuotes(Contract):
    field: NorthStarField
    quotes: list[Text] = Field(default_factory=list, max_length=6)


class NorthStarDraft(Contract):
    fields: list[FieldQuotes] = Field(default_factory=list, max_length=6)


class RuleVerdict(Contract):
    rule: Identifier
    passed: bool
    reason: Short
    options: list[Short] = Field(default_factory=list, max_length=3)

    word: Short
    prompt: bool
    reason: Short

    field: NorthStarField
```

```python
"""Deterministic claim provenance: computed status, quote tiling, novelty and scenario rules."""

import re
from typing import TYPE_CHECKING

from ..framework import ASPECTS
from .contracts import Claim, ClaimDraft, ClaimMapDraft, ClaimStatus, NotApplicable, Scenario, ScenarioDrafts

if TYPE_CHECKING:
    from ..domain import LedgerItem

STOPWORDS = frozenset(
    "a an the and or but if then else of to in on at by for with from as is are be been being was were "
    "it its this that these those i me my we our you your he she they them their can could should would "
    "will shall may might must do does did so such than too very just also into onto over under up down "
    "out off about after before again there here what which who whom".split()
)
NEGATIONS = frozenset({"no", "not", "never", "without", "none", "nothing", "cannot"})
TOKEN = re.compile(r"[a-z0-9]+(?:['’][a-z]+)?")


def normalize(token: str) -> str:
    token = token.replace("’", "'")
    if token in NEGATIONS or token.endswith("n't"):
        return "not"
    for suffix in ("ing", "ed", "s"):
        if token.endswith(suffix) and len(token) - len(suffix) >= 3:
            token = token[: -len(suffix)]
            break
    return token[:-1] if token.endswith("e") and len(token) > 3 else token


def content_words(text: str) -> list[str]:
    return [token for token in TOKEN.findall(text.casefold()) if token not in STOPWORDS]


def stems(text: str) -> set[str]:
    return {normalize(word) for word in content_words(text)}


def tag_ok(tag: str) -> bool:
    area, _, aspect = tag.partition("/")
    return area in ASPECTS and aspect in ASPECTS[area]


def novel_words(entry: ClaimDraft) -> list[str]:
    supported = set().union(*(stems(span.quote) for span in entry.spans)) if entry.spans else set()
    return list(dict.fromkeys(w for w in content_words(entry.text) if normalize(w) not in supported))


def computed_status(entry: ClaimDraft, items: dict) -> ClaimStatus:
    grounded = bool(entry.spans) and all(
        span.item_id in items
        and items[span.item_id].status == "confirmed"
        and span.quote in (items[span.item_id].source or "")
        for span in entry.spans
    )
    if entry.basis == "stated" and grounded:
        return "confirmed"
    if entry.basis == "excluded" and grounded:
        return "excluded"
    if entry.basis == "entailed" and entry.premises and entry.derivation:
        return "derived"
    return "proposal"


def build_claims(draft: ClaimMapDraft, ledger: list["LedgerItem"]) -> tuple[list[Claim], list[str]]:
    items = {item.id: item for item in ledger}
    ids = [f"C{index + 1}" for index in range(len(draft.claims))]
    claims, problems = [], []
    for claim_id, entry in zip(ids, draft.claims):
        flags = []
        problems.extend(f"{claim_id} uses unknown tag {tag}." for tag in entry.tags if not tag_ok(tag))
        for span in entry.spans:
            if span.item_id not in items:
                problems.append(f"{claim_id} cites unknown requirement {span.item_id}.")
            elif span.quote not in (items[span.item_id].source or ""):
                problems.append(f'{claim_id} quotes text not in {span.item_id}: "{span.quote}".')
        status = computed_status(entry, items)
        if entry.basis == "stated":
            novel = novel_words(entry)
            if novel:
                flags.append("novel: " + ", ".join(novel))
                status = "proposal"
                problems.append(
                    f"{claim_id} states words its quote does not support: {', '.join(novel)}. "
                    "Split the claim or label that part proposed."
                )
        if entry.basis == "delegated" and entry.reversibility > 1:
            problems.append(f"{claim_id} delegates a choice that is costly to reverse; ask the user.")
        if entry.basis in ("proposed", "delegated") and entry.serves is None:
            problems.append(f"{claim_id} is a proposal that serves no North Star field.")
        claims.append(Claim(**entry.model_dump(), id=claim_id, status=status, flags=flags))
    # Derived claims stand only on confirmed or derived premises.
    by_id = {claim.id: claim for claim in claims}
    for claim in claims:
        if claim.basis != "entailed":
            continue
        premises = [by_id.get(key) for key in claim.premises]
        if (
            not claim.premises
            or not claim.derivation
            or any(p is None or p.status not in ("confirmed", "derived") for p in premises)
        ):
            claim.status = "proposal"
            problems.append(f"{claim.id} needs existing premises and a derivation.")
    return claims, problems


def tiling_gaps(claims: list[Claim], ledger: list["LedgerItem"]) -> dict[str, list[str]]:
    covered: dict[str, set[str]] = {}
    for claim in claims:
        if claim.status in ("confirmed", "excluded"):
            for span in claim.spans:
                covered.setdefault(span.item_id, set()).update(stems(span.quote))
    gaps = {}
    for item in ledger:
        if item.status != "confirmed" or not item.source:
            continue
        missing = [
            word
            for word in dict.fromkeys(content_words(item.source))
            if normalize(word) not in covered.get(item.id, set())
        ]
        if missing:
            gaps[item.id] = missing
    return gaps


def aspect_gaps(
    claims: list[Claim], not_applicable: list[NotApplicable], ledger: list["LedgerItem"]
) -> list[str]:
    confirmed = {item.id for item in ledger if item.status == "confirmed"}
    mapped = {tag for claim in claims for tag in claim.tags}
    exempt = {entry.tag for entry in not_applicable if set(entry.ledger_ids) <= confirmed}
    return [
        f"{area}/{aspect}"
        for area, aspects in ASPECTS.items()
        for aspect in aspects
        if f"{area}/{aspect}" not in mapped | exempt
    ]


def build_scenarios(drafts: ScenarioDrafts, claims: list[Claim]) -> tuple[list[Scenario], list[str]]:
    known = {claim.id for claim in claims}
    scenarios = [
        Scenario(**entry.model_dump(), id=f"S{index + 1}") for index, entry in enumerate(drafts.scenarios)
    ]
    problems = [
        f"{s.id} exercises unknown claim {key}." for s in scenarios for key in s.claims if key not in known
    ]
    exercised = {key for s in scenarios for key in s.claims}
    behavior = [
        claim
        for claim in claims
        if claim.status in ("confirmed", "derived")
        and any(tag.split("/")[0] in ("journeys", "failure-recovery") for tag in claim.tags)
    ]
    problems.extend(f"No scenario exercises {c.id}: {c.text}" for c in behavior if c.id not in exercised)
    excluded = {key for s in scenarios if s.kind == "exclusion" for key in s.claims}
    problems.extend(
        f"No exclusion scenario shows {c.id}: {c.text}"
        for c in claims
        if c.status == "excluded" and c.id not in excluded
    )
    if not any(s.kind == "journey" for s in scenarios):
        problems.append("Add at least one journey scenario.")
    return scenarios, problems
```

```python
        "and stuff",
    ),
    "absolute": ("always", "never", "every", "all", "100%", "everything", "everyone", "nothing"),
    "comparative": ("better", "faster", "easier", "more", "less", "best", "worst"),
    "pronoun": ("it", "they", "them", "this", "that", "these", "those", "something", "someone"),
    "negation": ("not", "no", "without", "none", "nobody"),
}
TERMS = sorted(
    ((term, category) for category, words in LEXICON.items() for term in words),
    key=lambda pair: -len(pair[0]),
)


def scan(text: str) -> list[LexiconFlag]:
    lowered = text.casefold()
    taken: list[tuple[int, int]] = []
    flags: dict[str, tuple[int, LexiconFlag]] = {}
    for term, category in TERMS:
        for match in re.finditer(rf"(?<![\w-]){re.escape(term)}(?![\w-])", lowered):
            start, end = match.span()
            if any(start < other_end and other_start < end for other_start, other_end in taken):
                continue
            taken.append((start, end))
            flags.setdefault(term, (start, LexiconFlag(word=term, category=category, auto=category in AUTO)))
    return [flag for _, flag in sorted(flags.values(), key=lambda pair: pair[0])]
```

```python
"""North Star field evaluation; the application decides when a field is clear."""

import hashlib
import re
from collections import Counter
from typing import TYPE_CHECKING

from .contracts import (
    FIELD_LABELS,
    NORTH_STAR_FIELDS,
    PROMPT_ONCE_RULES,
    RUBRIC,
    RULE_TEXT,
    FieldState,
    NorthStarDraft,
    Probe,
    ProbeAnswer,
    Thresholds,
)

if TYPE_CHECKING:
    from ..domain import Candidate, Session

KEEP = "Keep my wording"
OWN = "I'll describe it myself"
QUESTIONS = {
    "who-when": "Who will use this, and in what moment do they reach for it?",
    "job": "In one phrase, what job should this do for them?",
    "ambition": "How big is this meant to be?",
    "today": "How is this done today, and what goes wrong with that?",
    "good": "When it works, what result would you notice, ideally with a number?",
    "fails-if": "What would make you say it failed? Describe something you could see happen.",
}
EXAMPLES = {
    "who-when": ["Only me, on my laptop, several times a day", "Me and two friends, on our phones, weekly"],
    "job": ["Save something to come back to later", "Track whether I did something today"],
    "ambition": ["A personal tool only I use, for months", "Shared with a few people for a year"],
    "today": ["I keep browser tabs open and lose them", "I use a notes app that gets cluttered"],
    "good": ["Find what I saved in under 10 seconds", "Finish the task in under a minute"],
    "fails-if": ["If something I saved disappears after a reload", "If I can't tell what I already did"],
}
UNSURE = re.compile(
    r"^\s*(i\s*(do\s*n[o']?t|dunno)\s*know|idk|not sure|no idea|you decide|whatever|up to you)\b", re.I
)


def text_hash(text: str) -> str:
    return hashlib.sha256(text.encode("utf-8")).hexdigest()


def slug(word: str) -> str:
    return re.sub(r"[^a-z0-9]+", "-", word.casefold()).strip("-")


def prompt_id(field: str, rule: str, word: str = "") -> str:
    return f"NS-{field}-{rule}" + (f"-{slug(word)}" if word else "")


def field_texts(draft: NorthStarDraft, user_texts: list[str]) -> tuple[dict[str, str], list[str]]:
    quotes: dict[str, list[str]] = {}
    problems = []
    for entry in draft.fields:
        for quote in entry.quotes:
            if any(quote in text for text in user_texts):
                quotes.setdefault(entry.field, []).append(quote)
            else:
                problems.append(f'North Star {entry.field} quote not found in your words: "{quote}"')
    return {field: " … ".join(dict.fromkeys(items)) for field, items in quotes.items()}, problems


def alpha_nominal(first: list[int], second: list[int]) -> float:
    """Krippendorff's alpha for two coders, nominal values, no missing data."""
    if len(first) != len(second) or not first:
        raise ValueError("Reader answers must align")
    counts = Counter([*first, *second])
    n = 2 * len(first)
    observed = 2 * sum(a != b for a, b in zip(first, second))
    expected = sum(counts[c] * counts[k] for c in counts for k in counts if c != k)
    if expected == 0:
        return 1.0 if observed == 0 else 0.0
    return 1 - (observed / n) / (expected / (n * (n - 1)))


def reader_result(probes: list[Probe], a: list[ProbeAnswer], b: list[ProbeAnswer]):
    if not probes:
        return None, [], [], False
    first, second = {x.probe_id: x.choice for x in a}, {x.probe_id: x.choice for x in b}
    ids = [probe.id for probe in probes]
    va, vb = [first.get(key, -1) for key in ids], [second.get(key, -1) for key in ids]
    disagree = [key for key, x, y in zip(ids, va, vb) if x != y]
    unclear = [key for key, x, y in zip(ids, va, vb) if -1 in (x, y)]
    one_way = any(probe.one_way and probe.id in disagree for probe in probes)
    return alpha_nominal(va, vb), disagree, unclear, one_way


def evaluate(
    state: FieldState, asked: set[str], readbacks: dict[str, str], thresholds: Thresholds
) -> FieldState:
    failing: list[str] = []
    if not state.text:
        failing.append("missing")
    else:
        judgement = state.judgement
        verdicts = {v.rule: v for v in (judgement.verdicts if judgement else [])}
        for rule in RUBRIC[state.field]:
            if rule not in verdicts:
                failing.append(f"judge:{rule}")
            elif not verdicts[rule].passed:
                failing.append(rule)
        rulings = {r.word.casefold(): r for r in (judgement.flag_rulings if judgement else [])}
        for flag in state.flags:
            ruling = rulings.get(flag.word)
            if (flag.auto or (ruling and ruling.prompt)) and prompt_id(
                state.field, "G1", flag.word
            ) not in asked:
                failing.append(f"G1:{flag.word}")
        for rule in PROMPT_ONCE_RULES.get(state.field, ()):
            verdict = verdicts.get(rule)
            if (verdict is None or not verdict.passed) and prompt_id(state.field, rule) not in asked:
                failing.append(rule)
        alpha, disagree, unclear, one_way = reader_result(state.probes, state.reader_a, state.reader_b)
        state.alpha = alpha
        if alpha is None:
            failing.append("G4:readers")
        else:
            failing.extend(f"G4:{key}" for key in unclear)
            if one_way or alpha < thresholds.alpha_pass:
                failing.extend(f"G4:{key}" for key in disagree)
        if readbacks.get(state.field) != state.text_hash:
            failing.append("G3")
    state.failing = list(dict.fromkeys(failing))
    state.passed = not state.failing
    return state


def _options(*groups: list[str]) -> list[str]:
    options = list(dict.fromkeys(item for group in groups for item in group if item.strip()))[:3]
    for filler in (OWN, KEEP):
        if len(options) >= 2:
            break
        if filler not in options:
            options.append(filler)
    return options


def _question(state: FieldState, code: str, revision: int) -> tuple[str, list[str], str]:
    label = FIELD_LABELS[state.field]
    verdicts = {v.rule: v for v in (state.judgement.verdicts if state.judgement else [])}
    if code == "missing" or code.startswith("judge:"):
        return (
            QUESTIONS[state.field],
            _options(EXAMPLES[state.field]),
            f"{prompt_id(state.field, 'missing')}-r{revision}",
        )
    if code.startswith("G1:"):
        word = code[3:]
        ruling = next(
            (
                r
                for r in (state.judgement.flag_rulings if state.judgement else [])
                if r.word.casefold() == word
            ),
            None,
        )
        options = _options((ruling.options if ruling else [])[:2], [KEEP])
        return (
            f'You said "{word}" in {label}. What exactly do you mean?',
            options,
            prompt_id(state.field, "G1", word),
        )
    if code.startswith("G4:"):
        probe = next((p for p in state.probes if p.id == code[3:]), None)
        if probe:
            return (
                f"In {label}: {probe.question}",
                _options(probe.options),
                f"{prompt_id(state.field, 'G4')}-r{revision}",
            )
        return (
            QUESTIONS[state.field],
            _options(EXAMPLES[state.field]),
            f"{prompt_id(state.field, 'G4')}-r{revision}",
        )
    verdict = verdicts.get(code)
    reason = f" {verdict.reason}" if verdict else ""
    if code in PROMPT_ONCE_RULES.get(state.field, ()):
        options = _options((verdict.options if verdict else [])[:2], [KEEP])
        return f"For {label}, can you {RULE_TEXT[code]}?{reason}", options, prompt_id(state.field, code)
    options = _options(verdict.options if verdict else [], EXAMPLES[state.field])
    return (
        f"For {label}, please {RULE_TEXT[code]}.{reason}",
        options,
        f"{prompt_id(state.field, code)}-r{revision}",
    )


def follow_up(
    fields: list[FieldState], drafts: list[str] | None, revision: int, assumed: list[str] = ()
) -> "Candidate | None":
    """Propose and confirm: a vague answer gets Intent's extrapolated draft to check."""
    from ..domain import Candidate

    by_field = {state.field: state for state in fields}
    for name in NORTH_STAR_FIELDS:
        state = by_field.get(name)
        if state is None or state.passed:
            continue
        codes = [code for code in state.failing if code != "G3"]
        if not codes:
            continue  # only the read-back confirmation remains; the UI asks for it
        question, options, key = _question(state, codes[0], revision)
        if drafts:
            guess = f' My best guess from what you told me: "{drafts[0]}".'
            filled = f" I filled in: {'; '.join(assumed)}." if assumed else ""
            question = f"{question}{guess}{filled} Does that fit? Pick one, or edit it."
            keep = [KEEP] if KEEP in options else []
            options = list(dict.fromkeys([*drafts[: 3 - len(keep)], *keep]))
        return Candidate(
            id=key,
            lens="north-star",
            targets=[],
            question=question[:500],
            options=options,
            code_diff=f"The {FIELD_LABELS[name]} answer sets which builds are proportionate "
            "and which choices Intent may make for you.",
            divergence=3,
            uncertainty=3,
            cost_to_change=3,
            suggestion=bool(drafts),
        )
    return None


def accept_drafted(fields: list[FieldState], session: "Session") -> None:
    """A field written entirely from drafts the user picked needs no separate read-back."""
    drafted = [turn.text for turn in session.turns if turn.suggested]
    for state in fields:
        parts = state.text.split(" … ") if state.text else []
        if parts and all(any(part in text for text in drafted) for part in parts):
            session.readbacks[state.field] = state.text_hash


def fatigued(session: "Session") -> bool:
    clicked = {asked.turn for asked in session.questions if asked.answer in asked.question.options}
    typed = [turn.text.strip() for turn in session.turns if turn.number not in clicked and not turn.suggested]
    if len(typed) >= 2 and all(UNSURE.search(text) for text in typed[-2:]):
        return True
    if len(typed) >= 2 and all(len(text.split()) == 1 for text in typed[-2:]):
        return True
    if len(typed) >= 5:
        baseline = sum(len(text) for text in typed[:3]) / 3
        return sum(len(text) for text in typed[-2:]) / 2 <= baseline / 2
    return False
```

```python
"""Decisions from candidate divergence; disposition by reversibility; Decision Quality links."""

import math
from collections import Counter
from typing import TYPE_CHECKING

from .contracts import Claim, Decision, DecisionProbe, ProbeAnswer, Scenario, Thresholds

if TYPE_CHECKING:
    from ..domain import AskedQuestion, Session

ONE_WAY = frozenset({"data-model", "identity", "external", "destructive"})
KANO_WEIGHT = {"must-be": 3, "performance": 2, "delighter": 1}
LINKS = ("frame", "alternatives", "information", "values", "reasoning", "commitment")
AGREEMENT = 0.7  # about 70% of the information you wish you had (Bezos, 2016 letter)


def split(votes: list[int]) -> float:
    counts = Counter(votes)
    if len(votes) < 2 or len(counts) == 1:
        return 0.0
    entropy = -sum(c / len(votes) * math.log(c / len(votes)) for c in counts.values())
    return entropy / math.log(min(len(votes), len(counts)))


def majority(votes: list[int]) -> tuple[int, int]:
    counts = Counter(v for v in votes if v >= 0)
    if not counts:
        return -1, 0
    choice = min(counts, key=lambda c: (-counts[c], c))
    return choice, counts[choice]


def delegate(decision: Decision, choice: int) -> None:
    decision.status, decision.owner = "delegated", "delegated"
    decision.outcome = decision.options[max(choice, 0)]
    agreeing = sum(v == max(choice, 0) for v in decision.votes)
    decision.because = (
        f"{decision.drivers[0]}: {agreeing} of {len(decision.votes)} candidate builds chose this"
    )


def dispose(decision: Decision, thresholds: Thresholds) -> None:
    choice, count = majority(decision.votes)
    if decision.reversibility == "one-way":
        decision.status = "open"
    elif count >= math.ceil(AGREEMENT * len(decision.votes)):
        delegate(decision, choice)
    elif decision.kano == "must-be":
        decision.status = "open"
    elif decision.kano == "delighter":
        if choice >= 0:
            delegate(decision, choice)
        else:
            decision.status = "excluded"
            decision.because = f"{decision.drivers[0]}: a nice-to-have nobody needs yet"
    elif decision.due_phase:
        decision.status = "deferred"
    else:
        decision.status = "open"
    # Stop rule (SAGE-Agent): low-value two-way questions become defaults; one-way never stops.
    if (
        decision.status == "open"
        and decision.reversibility == "two-way"
        and decision.score < thresholds.decision_stop
    ):
        delegate(decision, choice)


def build(
    probes: list[DecisionProbe], answers: list[list[ProbeAnswer]], asked: Counter, thresholds: Thresholds
) -> list[Decision]:
    decisions = []
    for probe in probes:
        votes = []
        for builder in answers:
            choice = next((a.choice for a in builder if a.probe_id == probe.id), -1)
            votes.append(choice if choice < len(probe.options) else -1)
        if len(set(votes)) == 1 and votes[0] >= 0:
            continue  # every candidate builds the same thing (ClarifyGPT)
        reversibility = "one-way" if probe.category in ONE_WAY else "two-way"
        spread = split(votes)
        score = spread * KANO_WEIGHT[probe.kano] * (3 if reversibility == "one-way" else 1)
        score -= thresholds.repeat_penalty * asked[probe.category]
        decision = Decision(
            id=f"D-{probe.id}",
            status="open",
            reversibility=reversibility,
            votes=votes,
            split=round(spread, 4),
            score=round(score, 4),
            **probe.model_dump(
                include={
                    "question",
                    "options",
                    "code_diff",
                    "context",
                    "drivers",
                    "kano",
                    "category",
                    "claims",
                    "pros",
                    "cons",
                    "due_phase",
                }
            ),
        )
        dispose(decision, thresholds)
        decisions.append(decision)
    return sorted(decisions, key=lambda d: (-d.score, d.id))


def resolve_vetoes(vetoes: list[Decision], asked: list["AskedQuestion"]) -> list[Decision]:
    answers = {entry.question.id: entry.answer for entry in asked}
    resolved = []
    for veto in vetoes:
        decision = veto.model_copy(deep=True)
        if decision.id in answers:
            decision.status, decision.owner = "decided", "user"
            decision.outcome = answers[decision.id]
            decision.because = f"{decision.drivers[0]}: your answer"
        else:
            decision.status, decision.owner, decision.outcome = "open", None, None
        resolved.append(decision)
    return resolved


def attach_confirmations(decisions: list[Decision], scenarios: list[Scenario]) -> None:
    for decision in decisions:
        decision.confirmation = next((s.id for s in scenarios if set(s.claims) & set(decision.claims)), None)


def quality(decision: Decision, claims: list[Claim], scenarios: list[Scenario]) -> dict[str, bool]:
    claim_ids, scenario_ids = {c.id for c in claims}, {s.id for s in scenarios}
    return {
        "frame": bool(decision.context) and bool(decision.drivers) and set(decision.claims) <= claim_ids,
        "alternatives": len(decision.options) >= 2 and len(decision.code_diff) >= 15,
        "information": len(decision.votes) >= 2,
        "values": decision.because is not None and any(d in decision.because for d in decision.drivers),
        "reasoning": bool(decision.claims),
        "commitment": decision.owner is not None and decision.confirmation in scenario_ids,
    }


def decision_problems(decisions: list[Decision]) -> list[str]:
    problems = []
    for decision in decisions:
        if decision.status == "open":
            problems.append(f"Decide: {decision.question}")
        elif decision.status in ("decided", "delegated"):
            missing = [link for link in LINKS if not decision.quality.get(link)]
            if missing:
                problems.append(
                    f"Complete the decision record for: {decision.question} ({', '.join(missing)})"
                )
            if decision.reversibility == "one-way" and decision.owner != "user":
                problems.append(f"Decide: {decision.question}")
    return problems


def wasted_questions(session: "Session") -> tuple[int, int]:
    """CLAM-style waste: an answer whose turn changed no ledger item."""
    changed = {item.turn for item in session.ledger}
    wasted = sum(entry.turn not in changed for entry in session.questions)
    return wasted, len(session.questions)
```

```python
"""Planted-defect calibration: an empty review must be earned (mutation testing of the reviewer)."""

import hashlib
import random
from collections import Counter

from .contracts import Canary, Claim, ClaimReview, ReviewState, Thresholds

INVENTED = (
    "It also asks for confirmation in a dialog first.",
    "It also emails a weekly summary.",
    "It also keeps a backup copy on a server.",
)
SCOPE_CREEP = "Add accounts and cloud sync so the list follows the user to every device."
VAGUE = "It handles this part appropriately and works well."
NEGATION = "It must not be true that "
COST = {"invented": 2, "negated": 3, "miscited": 2, "scope-creep": 3, "omitted": 3, "vague": 1}


def plant(
    claims: list[Claim], ledger_ids: list[str], seed: str
) -> tuple[list[Claim], list[Canary], dict[str, str]]:
    rng = random.Random(int(hashlib.sha256(seed.encode("utf-8")).hexdigest(), 16))
    stated = [c for c in claims if c.status == "confirmed"]
    copy = [c.model_copy(deep=True) for c in claims]
    by_id = {c.id: c for c in copy}
    planted: list[tuple[str, str]] = []
    picks = rng.sample(stated, k=min(4, len(stated)))
    for claim, kind in zip(picks, ("invented", "negated", "miscited", "vague")):
        target = by_id[claim.id]
        if kind == "invented":
            target.text = f"{target.text} {rng.choice(INVENTED)}"
        elif kind == "negated":
            target.text = NEGATION + target.text[0].lower() + target.text[1:]
        elif kind == "miscited":
            others = [key for key in ledger_ids if key not in {s.item_id for s in target.spans}]
            if not others:
                continue
            target.spans = [s.model_copy(update={"item_id": rng.choice(others)}) for s in target.spans]
        else:
            target.text = VAGUE
        planted.append((claim.id, kind))
    creep = Claim(
        id="C-new",
        text=SCOPE_CREEP,
        tags=["scope/included"],
        basis="proposed",
        serves="good",
        reversibility=3,
        status="proposal",
    )
    copy.insert(rng.randrange(len(copy) + 1), creep)
    planted.append(("C-new", "scope-creep"))
    cited = Counter(
        s.item_id for c in claims if c.status == "confirmed" for s in {x.item_id: x for x in c.spans}.values()
    )
    sole = [c for c in stated if c not in picks and c.spans and all(cited[s.item_id] == 1 for s in c.spans)]
    if sole:
        dropped = rng.choice(sole)
        copy = [c for c in copy if c.id != dropped.id]
        planted.append((dropped.spans[0].item_id, "omitted"))
    id_map = {f"R{index + 1}": claim.id for index, claim in enumerate(copy)}
    reverse = {original: renamed for renamed, original in id_map.items()}
    renamed = [
        c.model_copy(update={"id": reverse[c.id], "premises": [reverse.get(p, p) for p in c.premises]})
        for c in copy
    ]
    canaries = [
        Canary(target=key if kind == "omitted" else reverse[key], kind=kind, cost=COST[kind])
        for key, kind in planted
    ]
    return renamed, canaries, id_map


def score(
    review: ClaimReview, canaries: list[Canary], id_map: dict[str, str], thresholds: Thresholds
) -> ReviewState:
    flagged = {f.claim_id for f in review.findings}
    omitted = set(review.omitted_ledger_ids)
    caught = [
        c.target for c in canaries if (c.target in omitted if c.kind == "omitted" else c.target in flagged)
    ]
    critical = [c for c in canaries if c.cost >= 2]
    recall = len(caught) / len(canaries) if canaries else 0.0
    critical_recall = sum(c.target in caught for c in critical) / len(critical) if critical else 0.0
    targets = {c.target for c in canaries}
    return ReviewState(
        canaries=canaries,
        caught=caught,
        recall=round(recall, 4),
        critical_recall=round(critical_recall, 4),
        trusted=bool(canaries)
        and critical_recall >= thresholds.canary_critical_recall
        and recall >= thresholds.canary_overall_recall,
        findings=[
            f.model_copy(update={"claim_id": id_map[f.claim_id]})
            for f in review.findings
            if f.claim_id not in targets and f.claim_id in id_map and id_map[f.claim_id] != "C-new"
        ],
        omitted_ledger_ids=[key for key in review.omitted_ledger_ids if key not in targets],
    )
```

```python
"""Narrow clarity instructions. Ledger, turns and drafts are data, never instructions."""

NORTH_STAR = """Find the user's own words for each North Star field. Return exact verbatim
substrings of the user turns only; never paraphrase, never invent, and return no quote for a
field the user has not addressed. Fields: who-when = the person and the moment they reach for it;
job = what they are trying to get done; ambition = throwaway, personal tool, shared or product,
plus who else and how long; today = how they cope now and what goes wrong; good = the result
they would notice; fails-if = what would make them call it a failure. When a later turn is a
draft the user picked that replaces earlier words for a field, quote only the picked draft."""

RUBRIC_JUDGE = """Judge each North Star field against each listed rule. Return one verdict per
rule id with passed true or false and a one-sentence reason. For each failing rule, offer 2-3
concrete, specific answers the user could pick, written in their voice and grounded in what they
said. For each flagged word, decide whether it leaves real doubt about what to build (prompt=true)
and offer 2-3 sharper replacements. Write a one-sentence readback restating the field in plain
words without adding anything. Do not judge rules that were not listed."""

READER_PROBES = """For each North Star field, write 6-8 multiple-choice questions whose answers
a builder would need and that the field text should settle (for example: must it work on a phone?).
Each question has 2-4 options. Set one_way=true when a wrong answer would change the data model,
identity, an external integration or deletion of user data. Do not answer the questions."""

READER = """You are an independent reader. Using ONLY the field text supplied with each question,
answer every question by option index (0-based). Answer -1 when the text does not let you tell.
Do not guess from what similar products usually do."""

SUGGEST = """The user has an idea but may not know the details a builder needs; you are the
builder. For this North Star field, extrapolate the most plausible specific answer from everything
they said, filling each gap with a concrete, proportionate assumption. Write 2-3 alternative complete
answers in the user's voice (first person), each satisfying the failing checks: concrete, measurable
where asked, and free of vague words such as easy, fast, simple or etc. List every assumption you
added in assumed, in plain words, so the user can check it. Do not add features, accounts, servers,
integrations or scale the idea does not need. The user will confirm or correct your draft."""

CLAIMS = """Map the product into atomic claims: one assertion each, at most about 25 words.
basis=stated only when the claim says nothing beyond its spans; each span quotes an exact substring
of the cited ledger item's source. Keep the user's words. Split any claim that would add a detail.
basis=entailed needs premises (claim ids C1.. in output order) and a one-sentence derivation.
basis=delegated is a reversible default the user explicitly delegated; it cites that delegation.
basis=proposed is your implementation choice; set serves to the North Star field it serves.
basis=excluded restates an explicit exclusion. Tag each claim with area/aspect from required_tags.
For an aspect that truly does not apply, add not_applicable with a reason and confirmed ledger ids.
Never invent accounts, servers, sync, payments or scale the North Star does not need.
If review_feedback is present, fix every listed problem and unmapped word without changing meaning."""

SCENARIOS = """Write Given/When/Then scenarios the user can confirm in seconds, in domain words,
not UI mechanics. Include at least one journey scenario, one scenario per failure or recovery
claim, and one exclusion scenario per excluded claim. List the claim ids each scenario exercises.
Every Then must follow from the listed claims; if it does not, the claims are incomplete."""

DECISION_PROBES = """List the points where two reasonable builders could build different code
from these claims. Seed from critic_questions. Each probe has 2-3 options with the concrete code
difference, context citing claim ids, the North Star fields it serves (drivers), a Kano class
(must-be, performance, delighter), a category (data-model, identity, external, destructive,
behavior, presentation, other) and, only if it can safely wait, a due_phase like P2.
Do not reopen settled answers or explicit exclusions. Do not ask cosmetic questions."""

CANDIDATE = """You are one of several independent builders. Using the North Star and claims only,
answer each probe by the option index you would actually build (0-based), or -1 if nothing tells you."""

REVIEW = """Audit these claims against the ledger and turns. Report every claim that is invented,
negated, cites the wrong requirement, is vague, or adds scope the North Star does not need, using
its id. List confirmed ledger ids that no claim represents in omitted_ledger_ids. A citation does
not prove support. An empty result is a strong claim; be thorough."""

ENTAILMENT = """For each claim, decide whether its text asserts anything that its quoted sources
(or premises) do not. entailed=false if it adds any behavior, value, order, gesture, name or limit;
put the added part in extra."""

ALIGN = """Compare the restated requirements with the confirmed ledger items. Return the ids of
ledger items no restatement expresses, and the indices of restatements no ledger item supports."""
```

```python
"""Clarity v2 passes. Models answer narrow questions; the application decides."""

import asyncio
from collections import Counter

from ..framework import ASPECTS, source_hash
from ..models import ModelError
from . import prompts
from .canary import plant, score
from .contracts import (
    FIELD_LABELS, NORTH_STAR_FIELDS, PROMPT_ONCE_RULES, RUBRIC, RULE_TEXT,
    Alignment, Answers, ClaimMapDraft, ClaimReview, ClarityState, DecisionProbes, Entailment,
    FieldState, NorthStarDraft, NorthStarProbes, RoundTrip, RubricJudgement, ScenarioDrafts,
    Suggestions, Thresholds,
)
from .decisions import attach_confirmations, quality, resolve_vetoes
from .decisions import build as build_decisions
from .lexicon import scan
from .gate import describe
from .northstar import accept_drafted, evaluate, fatigued, field_texts, follow_up, text_hash
from .provenance import aspect_gaps, build_claims, build_scenarios, tiling_gaps

CANDIDATES = 4


class ClarityPipeline:
    def __init__(self, call, save, thresholds: Thresholds):
        self.call, self.save, self.thresholds = call, save, thresholds

    async def run(self, session, seeds: list[str]):
        state = ClarityState(revision=session.revision, source_hash=source_hash(session),
                             mode=session.mode, thresholds=self.thresholds, seeds=seeds)
        session.clarity = state
        try:
            await self.north_star(session, state)
        except (ModelError, ValueError) as error:
            state.failures.append(f"north-star: {error}"[:500])
        self.save(session)
        if not state.failures and all(f.passed for f in state.fields):
            await self.downstream(session, state)
            self.save(session)
        return self.questions(session, state)

    async def refresh(self, session):
        state = session.clarity
        self.refresh_fields(session, state)
        if not state.failures and not state.downstream_complete and all(f.passed for f in state.fields):
            await self.downstream(session, state)
        self.save(session)
        return self.questions(session, state)

    def refresh_fields(self, session, state):
        asked = {entry.question.id for entry in session.questions}
        for field in state.fields:
            evaluate(field, asked, session.readbacks, state.thresholds)

    async def north_star(self, session, state):
        user_texts = [turn.text for turn in session.turns]
        draft = await self.call(session, "clarity:north-star", NorthStarDraft, prompts.NORTH_STAR,
                                {"turns": [{"number": t.number, "text": t.text} for t in session.turns]})
        texts, _ = field_texts(draft, user_texts)  # invalid quotes are dropped, like ledger sources
        state.fields = [
            FieldState(field=name, text=texts.get(name, ""), text_hash=text_hash(texts.get(name, "")),
                       flags=scan(texts.get(name, "")))
            for name in NORTH_STAR_FIELDS
        ]
        present = [f for f in state.fields if f.text]
        if present:
            judge_payload = {"fields": [{
                "field": f.field, "text": f.text, "flags": [flag.word for flag in f.flags],
                "rules": {rule: RULE_TEXT[rule] for rule in (*RUBRIC[f.field], *PROMPT_ONCE_RULES.get(f.field, ()))},
            } for f in present]}
            judgement, probe_sets = await asyncio.gather(
                self.call(session, "clarity:rubric", RubricJudgement, prompts.RUBRIC_JUDGE, judge_payload),
                self.call(session, "clarity:probes", NorthStarProbes, prompts.READER_PROBES,
                          {"fields": [{"field": f.field, "text": f.text} for f in present]}),
            )
            judged = {entry.field: entry for entry in judgement.fields}
            sets = {entry.field: entry.probes for entry in probe_sets.sets}
            for f in present:
                f.judgement = judged.get(f.field)
                f.probes = [p.model_copy(update={"id": f"{f.field}.p{i + 1}"}) for i, p in enumerate(sets.get(f.field, []))]
            reader_payload = {"fields": [{
                "field": f.field, "text": f.text,
                "questions": [p.model_dump(include={"id", "question", "options"}) for p in f.probes],
            } for f in present]}
            first, second = await asyncio.gather(
                self.call(session, "clarity:reader:a", Answers, prompts.READER, reader_payload),
                self.call(session, "clarity:reader:b", Answers, prompts.READER, reader_payload),
            )
            for f in present:
                ids = {p.id for p in f.probes}
                f.reader_a = [x for x in first.answers if x.probe_id in ids]
                f.reader_b = [x for x in second.answers if x.probe_id in ids]
        accept_drafted(state.fields, session)
        self.refresh_fields(session, state)
        state.fatigued = fatigued(session)  # recorded for evals; drafting does not wait for fatigue
        target = next((f for f in state.fields if not f.passed and set(f.failing) - {"G3"}), None)
        if target:
            drafts = await self.call(session, "clarity:suggest", Suggestions, prompts.SUGGEST, {
                "field": target.field, "label": FIELD_LABELS[target.field], "current": target.text,
                "failing": [describe(code) for code in target.failing if code != "G3"],
                "turns": [t.text for t in session.turns],
            })
            screened = [d for d in drafts.drafts if not any(flag.auto for flag in scan(d))]
            state.suggestions = screened if len(screened) >= 2 else []
            state.assumed = list(drafts.assumed) if state.suggestions else []

    async def downstream(self, session, state):
        base = {
            "north_star": {f.field: f.text for f in state.fields},
            "ledger": [item.model_dump(mode="json") for item in session.ledger],
            "turns": [{"number": t.number, "text": t.text} for t in session.turns],
            "required_tags": [f"{area}/{aspect}" for area, aspects in ASPECTS.items() for aspect in aspects],
        }
        try:
            feedback = None
            for attempt in range(2):
                payload = {**base, **({"review_feedback": feedback} if feedback else {})}
                draft = await self.call(session, "clarity:claims", ClaimMapDraft, prompts.CLAIMS, payload)
                claims, problems = build_claims(draft, session.ledger)
                gaps = tiling_gaps(claims, session.ledger)
                tags = aspect_gaps(claims, draft.not_applicable, session.ledger)
                if attempt or not (problems or gaps or tags):
                    break
                feedback = {"problems": problems, "unmapped_words": gaps, "unmapped_tags": tags}
            state.claims, state.not_applicable, state.problems = claims, draft.not_applicable, problems
            claim_payload = [c.model_dump(mode="json") for c in claims]
            scenario_drafts, probe_set = await asyncio.gather(
                self.call(session, "clarity:scenarios", ScenarioDrafts, prompts.SCENARIOS,
                          {**base, "claims": claim_payload}),
                self.call(session, "clarity:decision-probes", DecisionProbes, prompts.DECISION_PROBES, {
                    **base, "claims": claim_payload, "critic_questions": state.seeds,
                    "settled": [entry.question.question for entry in session.questions],
                }),
            )
            state.scenarios, scenario_problems = build_scenarios(scenario_drafts, claims)
            state.problems.extend(scenario_problems)
            probes = [p.model_copy(update={"id": f"P{i + 1}"}) for i, p in enumerate(probe_set.probes)]
            builders = []
            if probes:
                builder_payload = {
                    "north_star": base["north_star"], "claims": claim_payload,
                    "probes": [p.model_dump(include={"id", "question", "options"}) for p in probes],
                }
                builders = await asyncio.gather(*[
                    self.call(session, f"clarity:candidate:{index + 1}", Answers, prompts.CANDIDATE, builder_payload)
                    for index in range(CANDIDATES)
                ])
            asked = Counter(
                entry.question.id.split(":")[1] for entry in session.questions
                if entry.question.lens == "decision" and entry.question.id.startswith("D:")
            )
            decisions = build_decisions(probes, [b.answers for b in builders], asked, state.thresholds)
            decisions.extend(resolve_vetoes(session.vetoes, session.questions))
            attach_confirmations(decisions, state.scenarios)
            for decision in decisions:
                decision.quality = quality(decision, claims, state.scenarios)
            state.decisions = decisions
            state.review = await self.review(session, state, base)
            state.downstream_complete = True
        except (ModelError, ValueError) as error:
            state.failures.append(f"clarity: {error}"[:500])

    async def review(self, session, state, base):
        confirmed = [item.id for item in session.ledger if item.status == "confirmed"]
        mutated, canaries, id_map = plant(state.claims, confirmed, state.source_hash)
        by_id = {c.id: c for c in state.claims}
        checkable = [c for c in state.claims if c.status in ("confirmed", "derived")]
        review_call = self.call(session, "clarity:review", ClaimReview, prompts.REVIEW,
                                {**base, "claims": [c.model_dump(mode="json") for c in mutated]})
        roundtrip_call = self.call(session, "clarity:roundtrip", RoundTrip, prompts.ROUNDTRIP, {
            "claims": [c.text for c in state.claims if c.status != "proposal"],
            "scenarios": [s.model_dump(mode="json") for s in state.scenarios],
        })
        if checkable:
            entail_call = self.call(session, "clarity:entailment", Entailment, prompts.ENTAILMENT, {"claims": [{
                "claim_id": c.id, "text": c.text, "sources": [s.quote for s in c.spans],
                "premises": [by_id[p].text for p in c.premises if p in by_id],
            } for c in checkable]})
            review, roundtrip, entail = await asyncio.gather(review_call, roundtrip_call, entail_call)
        else:
            review, roundtrip = await asyncio.gather(review_call, roundtrip_call)
            entail = Entailment()
        result = score(review, canaries, id_map, state.thresholds)
        verdicts = {v.claim_id: v for v in entail.verdicts}
        result.entailment_failures = [c.id for c in checkable if c.id not in verdicts or not verdicts[c.id].entailed]
        alignment = await self.call(session, "clarity:align", Alignment, prompts.ALIGN, {
            "restated": roundtrip.requirements,
            "ledger": [{"id": i.id, "text": i.text} for i in session.ledger if i.status == "confirmed"],
        })
        result.roundtrip_missing = [key for key in alignment.missing_ledger_ids if key in set(confirmed)]
        return result

    def questions(self, session, state):
        from ..domain import Candidate

        question = follow_up(state.fields, state.suggestions or None, session.revision, state.assumed)
        if question:
            return [question]
        if not state.downstream_complete:
            return []
        open_decisions = [d for d in state.decisions if d.status == "open"]
        return [
            Candidate(
                id=d.id if d.id.startswith("V") else f"D:{d.category}:{session.revision}:{index + 1}",
                lens="decision", targets=[], question=d.question, options=d.options, code_diff=d.code_diff,
                divergence=3, uncertainty=3 if d.reversibility == "one-way" else 2,
                cost_to_change=3 if d.reversibility == "one-way" else 2,
            )
            for index, d in enumerate(open_decisions)
        ]
```

```python
"""Clarity v2 readiness, readout, approval and handoff context. Application-owned."""

from ..framework import source_hash
from .contracts import FIELD_LABELS, NORTH_STAR_FIELDS, RULE_TEXT
from .decisions import decision_problems
from .provenance import aspect_gaps, tiling_gaps


def is_current(session) -> bool:
    state = session.clarity
    return bool(state and state.revision == session.revision and state.mode == session.mode
                and state.source_hash == source_hash(session))


def describe(code: str) -> str:
    if code == "missing":
        return "not answered yet"
    if code == "G3":
        return "confirm Intent's read-back"
    if code.startswith("G1:"):
        return f'clarify "{code[3:]}" (or keep your wording)'
    if code.startswith("G4:"):
        return "two independent readers understood this differently"
    if code.startswith("judge:"):
        return f"the rubric judge did not check {code[6:]}; analyze again"
    return RULE_TEXT.get(code, code)


def clarity_blockers(session) -> list[str]:
    state = session.clarity
    if state is None:
        return ["Check the North Star, claims and decisions for this revision."]
    if not is_current(session):
        return ["The clarity review is stale. Analyze the current requirements again."]
    blockers = list(state.failures)
    fields = {f.field: f for f in state.fields}
    for name in NORTH_STAR_FIELDS:
        field = fields.get(name)
        if field is None:
            blockers.append(f"North Star {FIELD_LABELS[name]}: not checked yet")
        elif not field.passed:
            blockers.append(f"North Star {FIELD_LABELS[name]}: {describe(field.failing[0])}")
    if len(blockers) > len(state.failures):
        return list(dict.fromkeys(blockers))
    if not state.downstream_complete:
        blockers.append("Map claims, scenarios and decisions.")
        return list(dict.fromkeys(blockers))
    blockers.extend(state.problems)
    blockers.extend(f'Map "{" ".join(words)}" from {key}.' for key, words in tiling_gaps(state.claims, session.ledger).items())
    blockers.extend(f"Map {tag} or mark it not applicable with a citation."
                    for tag in aspect_gaps(state.claims, state.not_applicable, session.ledger))
    blockers.extend(decision_problems(state.decisions))
    review = state.review
    if review is None:
        blockers.append("Complete the calibrated claim review.")
    else:
        if not review.trusted:
            blockers.append(f"Framework review could not be verified: it caught {len(review.caught)} "
                            f"of {len(review.canaries)} planted defects.")
        blockers.extend(f"Review {f.claim_id}: {f.detail}" for f in review.findings)
        blockers.extend(f"Review: {key} is not represented by any claim." for key in review.omitted_ledger_ids)
        blockers.extend(f"Claim {key} says more than its source." for key in review.entailment_failures)
        blockers.extend(f"Round-trip could not reconstruct {key}." for key in review.roundtrip_missing)
    if not state.scenarios:
        blockers.append("Write scenarios for approval.")
    return list(dict.fromkeys(blockers))


def clarity_progress(session) -> float:
    if not is_current(session):
        return 0
    state = session.clarity
    fields = sum(f.passed for f in state.fields) / len(NORTH_STAR_FIELDS)
    rest = 0.5 if state.downstream_complete and not clarity_blockers(session) else 0.25 if state.downstream_complete else 0
    return fields * 0.5 + rest


def readout(session) -> dict | None:
    if not is_current(session):
        return None
    state = session.clarity
    return {
        "statements": sum(c.status in ("confirmed", "excluded") for c in state.claims),
        "unmapped_words": sum(len(w) for w in tiling_gaps(state.claims, session.ledger).values()),
        "choices_made": sum(d.status == "delegated" for d in state.decisions),
        "decisions_open": sum(d.status == "open" for d in state.decisions),
        "scenarios": len(state.scenarios),
    }


def approval_ready(session) -> bool:
    if session.clarity_version == 2:
        return is_current(session) and bool(session.clarity.scenarios)
    return session.playback_revision == session.revision


def reviewed_clarity(session) -> dict | None:
    if not is_current(session) or clarity_blockers(session):
        return None
    state = session.clarity
    return {
        "note": "Claims labeled proposal are reviewed proposals, not user requirements.",
        "north_star": {f.field: f.text for f in state.fields},
        "claims": [c.model_dump(mode="json", include={"id", "text", "tags", "status", "spans"}) for c in state.claims],
        "scenarios": [s.model_dump(mode="json") for s in state.scenarios],
        "decisions": [d.model_dump(mode="json") for d in state.decisions if d.status != "open"],
    }


def brief_lines(session) -> list:
    from ..domain import BriefLine

    if reviewed_clarity(session) is None:
        return []
    state = session.clarity
    lines = [
        BriefLine(section=f"Clarity {c.status}: {c.tags[0].split('/')[0]}", text=c.text,
                  ledger_ids=list(dict.fromkeys(s.item_id for s in c.spans)) or [f"NS-{c.serves or 'map'}"])
        for c in state.claims
    ]
    lines.extend(BriefLine(section="Done when (approved scenarios)",
                           text=f"{s.title}: given {s.given}, when {s.when}, then {s.then}",
                           ledger_ids=[s.id, *s.claims]) for s in state.scenarios)
    lines.extend(BriefLine(section="Choices made for you" if d.status == "delegated" else "Decisions",
                           text=f"{d.question} -> {d.outcome or d.status} ({d.because or d.due_phase or ''})",
                           ledger_ids=[d.id]) for d in state.decisions if d.status != "open")
    return lines[:200]
```

```python
def demo_clarity(session, role, payload):

        return RubricJudgement(fields=[FieldJudgement(
            field=entry["field"], readback=f"Scripted read-back: {entry['text'][:200]}",
            verdicts=[RuleVerdict(rule=rule, passed=True, reason="Scripted pass")
                      for rule in (*RUBRIC[entry["field"]], *PROMPT_ONCE_RULES.get(entry["field"], ()))],
            flag_rulings=[FlagRuling(word=word, prompt=False, reason="Scripted ruling") for word in entry["flags"]],
        ) for entry in payload["fields"]])
    if role == "clarity:probes":
        return NorthStarProbes(sets=[ProbeSet(field=entry["field"], probes=[
            Probe(id=f"p{i}", question=f"Scripted probe {i}?", options=["Yes", "No"]) for i in range(1, 7)
        ]) for entry in payload["fields"]])
    if role.startswith("clarity:reader:") or role.startswith("clarity:candidate:"):
        questions = [q for entry in payload.get("fields", []) for q in entry["questions"]] or payload.get("probes", [])
        return Answers(answers=[ProbeAnswer(probe_id=q["id"], choice=0) for q in questions])
    if role == "clarity:suggest":
        return Suggestions(drafts=["Scripted draft: only me, on my laptop, daily",
                                   "Scripted draft: me and two friends, weekly"],
                           assumed=["Scripted assumption: a laptop browser"])
    if role == "clarity:claims":
        confirmed = [item for item in session.ledger if item.status == "confirmed" and item.source]
        claims = [ClaimDraft(
            text=item.source, tags=[SLOT_TAGS.get(item.slot, "journeys/actions")],
            basis="excluded" if item.slot == "non-goals" or item.type == "non-goal" else "stated",
            spans=[Span(item_id=item.id, quote=item.source)],
        ) for item in confirmed]
        used = {claim.tags[0] for claim in claims}
        cite = [confirmed[0].id] if confirmed else []
        return ClaimMapDraft(claims=claims, not_applicable=[
            NotApplicable(tag=f"{area}/{aspect}", reason="Scripted sample", ledger_ids=cite)
            for area, aspects in ASPECTS.items() for aspect in aspects
            if f"{area}/{aspect}" not in used and cite
        ])
    if role == "clarity:scenarios":
        claims = payload["claims"]
        journey = [c["id"] for c in claims if c["tags"][0].split("/")[0] in ("journeys", "failure-recovery")]
        excluded = [c["id"] for c in claims if c["status"] == "excluded"]
        scenarios = [ScenarioDraft(title="Scripted journey", given="the app is open", when="the main action runs",
                                   then="the confirmed result is visible", claims=journey or [claims[0]["id"]],
                                   kind="journey")]
        if excluded:
            scenarios.append(ScenarioDraft(title="Scripted exclusion", given="a request for an excluded feature",
                                           when="the user looks for it", then="it is not offered",
                                           claims=excluded, kind="exclusion"))
        return ScenarioDrafts(scenarios=scenarios)
    if role == "clarity:decision-probes":
        return DecisionProbes()
    if role == "clarity:review":
        # Scripted reviewer: recognizes the application's own mutation catalogue. Demo only.
        ledger = {item["id"]: item for item in payload["ledger"]}
        findings = []
        for claim in payload["claims"]:
            text = claim["text"]
            miscited = any(span["quote"] not in (ledger.get(span["item_id"], {}).get("source") or "")
                           for span in claim["spans"])
            if (text in (VAGUE, SCOPE_CREEP) or text.startswith(NEGATION)
                    or any(text.endswith(extra) for extra in INVENTED) or miscited):
                findings.append(ReviewFinding(claim_id=claim["id"], kind="other", detail="Scripted catch"))
        # A quote represents every item whose source contains it, so a miscited claim
        # still represents its true item; only a dropped claim leaves an item uncovered.
        quotes = [span["quote"] for claim in payload["claims"] for span in claim["spans"]]
        omitted = [key for key, item in ledger.items() if item["status"] == "confirmed" and item["source"]
                   and not any(quote in item["source"] for quote in quotes)]
        return ClaimReview(findings=findings, omitted_ledger_ids=omitted)
    if role == "clarity:entailment":
        return Entailment(verdicts=[{"claim_id": c["claim_id"], "entailed": True} for c in payload["claims"]])
    if role == "clarity:roundtrip":
        return RoundTrip(requirements=payload["claims"][:60])
    if role == "clarity:align":
        return Alignment()
    raise ValueError(f"Unknown demo role: {role}")
```

```python
"""Clarity eval metrics. Scripted runs measure plumbing, not model quality."""

from .decisions import wasted_questions


def clarity_metrics(session) -> dict | None:
    if session.clarity_version != 2 or session.clarity is None:
        return None
    state = session.clarity
    wasted, asked = wasted_questions(session)
    return {
        "fields_passed": sum(f.passed for f in state.fields),
        "alpha": {f.field: f.alpha for f in state.fields if f.alpha is not None},
        "failing": {f.field: f.failing for f in state.fields if f.failing},
        "claims": len(state.claims),
        "problems": len(state.problems),
        "decisions": {status: sum(d.status == status for d in state.decisions)
                      for status in ("open", "decided", "delegated", "deferred", "excluded")},
        "review_recall": state.review.recall if state.review else None,
        "review_critical_recall": state.review.critical_recall if state.review else None,
        "review_trusted": state.review.trusted if state.review else None,
        "wasted_questions": [wasted, asked],
    }
```
