## Decisions, rationale, and invariants

- Questions are explanatory model calls using existing Super routing and budget;
  they cannot mutate intent, plans, approvals, tools or execution. Replies must cite
  server-supplied addresses. Model text is rendered as text, not executable HTML.
- Direction requires preview and explicit submission. Save exact human text as a
  turn; scope and context remain separate. Use the existing extraction/critic flow
  and invalidate affected execution before inference. Failure must keep gates closed.
- Bind requests/history/drafts to session, requirements revision, plan ID/revision/hash,
  node ID and node-body hash. Historical threads remain read-only. Activity is an
  overlay and never changes canonical plan content.
- Reserve request IDs durably before external effects. Same payload returns its
  saved result; conflicting reuse is rejected. Restart marks pending requests uncertain.
  Explicitly starting a different message preserves the uncertain original in history.
- Legacy turns omit null scope in serialization, preserving existing hashes.
- Keep one trusted local user, one orchestrator process and loopback binding. The
  app has no account authentication. Codex supports bounded workers under one
  configured account home; multi-account scheduling and mixed-agent execution are
  not implemented. Claude's self-contained HTML builder is separate.
